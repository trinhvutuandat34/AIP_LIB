교수님, 안녕하십니까. [팀명/학번/성함]입니다.

AI Pilot 경진대회 참가 준비를 하며 팀 트리를 설계·검증하는 과정에서 느낀 점이
있어 말씀드립니다.

대회 안내 자료에 "AI 경진대회이기 이전에 AI를 활용한 BFM 교육 프로그램"이라고
명시되어 있는데, 실제로 참가팀들과 이야기해보면 **행동트리(BT)에 대한 이해도와
공중전(BFM) 지식 수준이 팀마다 상당히 차이가 나는 것 같습니다.** SDK 의
REFERENCE.md·RULEBOOK.md·예제 4종(starter/energy_fighter/textbook_headon/
doctrine_regulator)은 이미 잘 정리되어 있지만, 이 자료들은 "BT 문법을 이미
알고 BFM 용어(ATA·AA·HCA, 1서클/2서클, 요요 기동 등)에 어느 정도 익숙한
사람"을 기준으로 쓰여 있어서, 두 배경 지식이 모두 부족한 팀은 진입 장벽을
크게 느끼는 것 같습니다.

그래서 제안드리고 싶은 것은, 참가팀 전체가 공통으로 참고할 수 있는
**"스타터 팩"**을 별도로 만들어 배포하는 것입니다. 대략 이런 내용이면
좋겠다고 생각합니다.

1. **BT 개념 자체를 처음부터 설명하는 자료** — selector/sequence/condition
   /action 이 각각 무엇이고 왜 이런 구조로 짜는지, "왜 조건 게이트에 거리
   조건이 꼭 필요한가" 같은 SDK 예제들이 전제하고 있는 배경 지식을 그림과
   함께 풀어주는 자료.
2. **BFM(공중전) 기초를 대회 용어에 맞춰 설명하는 자료** — ATA/AA/HCA 가
   각각 무엇을 재는 각도인지, HABFM/OBFM/DBFM 국면이 무엇인지, 요요·
   컨트롤존·1서클/2서클 같은 개념을 그림 한 장으로 이해할 수 있는 자료.
   (BEM 교범 원문은 방대해서, 이번 대회에서 실제로 쓰는 부분만 추린 요약본이면
   충분할 것 같습니다.)
3. **아주 단순한 트리 하나를 처음부터 끝까지 설계해보는 실습 예제** — 기존
   `examples/starter.yaml` 보다 한 단계 더 쉬운, "왜 이 줄을 이렇게 썼는지"를
   한 줄 한 줄 설명하는 버전. 여기에 `tools/validate_agent.py`·
   `scripts/run_match.py` 로 직접 검증·자가대전 해보는 순서까지 안내하면
   좋을 것 같습니다.
4. **자주 하는 실수 체크리스트** — 거리 게이트 없이 방어 분기를 짜서
   오발동하는 경우, `commit` 없이 요요를 짜서 매 tick 뒤집히는 경우처럼,
   문법은 맞지만 실전에서 흔히 걸리는 함정들.

이렇게 하면 모든 팀이 최소한 "같은 출발선"에서 전술 설계라는 본질적인
부분에 집중할 수 있을 것 같고, 대회의 원래 취지인 "BFM 교육 프로그램"에도
더 잘 맞을 것 같습니다.

혹시 필요하시다면 저희 팀에서 그동안 트리를 설계·검증하며 정리한 내용을
바탕으로 초안 작성을 도와드릴 수도 있습니다. 검토 부탁드리며, 편하실 때
말씀해 주시면 감사하겠습니다.
