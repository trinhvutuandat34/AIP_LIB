> 트리를 짜는 데 실제로 필요한 부분만 추린 요약이다.

## 2.1 대회는 2계층으로 돈다

| 계층 | 상대 | 목적 | 결선 진출에 반영 |
|---|---|---|---|
| **훈련센터** | 대항군(고정 5종) | 상시 자가 진단 | **아니다** |
| **예선 라운드** | 참가팀 전원 | 라운드마다 위너 배출 | 위너가 진출 |
| **결선 진출 풀리그** | 참가팀 전원 | 잔여 진출권 배분 | 상위 팀이 진출 |

- **훈련센터는 연습장이다.** 아무 때나 제출해서 대항군 5종 × 시나리오 4종 ×
  시드 2개 = **40경기** 배터리로 자기 트리를 점검한다. 결선 진출과는 무관하니
  마음껏 실험할 것. (이 프로젝트가 실제로 이 배터리를 두 라운드 돌리며 트리를
  개선한 기록이 [06장](06_lessons_from_the_trenches.md)에 있다.)
- **예선 라운드는 독립제** — 라운드마다 새로 겨루고 성적이 누적되지 않는다.
  마감 시점의 제출물이 그 라운드의 출전작으로 확정된다(별도 신청 없이 자동
  참가).
- **결선 진출**은 예선 라운드 위너 전원 + 풀리그 상위 팀으로 채워진다.

## 2.2 매치 기본 값

| 항목 | 값 |
|---|---|
| 교전 시간 | 300초 |
| 초기 HP | 각 100 |
| 하드덱(고도 하한) | **1,000 ft 미만 = 즉시 패** |
| 실속(속도 하한) | **100 kts 미만 누적 10초 = 즉시 패** |
| 트리 평가 주기 | 20 Hz |

## 2.3 시나리오 4종 — 골고루 잘해야 한다

리그는 아래 4국면을 **모두** 평가한다. 한 국면만 잘하는 트리는 순위를 못 얻는다.

| 시나리오 | BEM 국면 | 초기 상황 |
|---|---|---|
| `headon` | HABFM(대등) | 서로 마주보고 접근, 약 6NM |
| `perch_offense` | OBFM(공세) | 내가 적 후방 6,000ft + 속도 +100kt 우위 |
| `perch_defense` | DBFM(수세) | 위 상황의 진영 교대 — 내가 열위 |
| `neutral` | 중립 머지 | 측방 3,000ft 이격, 역할 대칭 |

(참가자 간 실전 대전은 `duel` 시나리오를 쓴다 — `headon`과 기하는 같지만 양측
초기 조준 오차를 동일하게 맞춰 운을 없앤 버전. 연습 시엔 `headon`으로 충분하다.)

## 2.4 총(Gun WEZ) 판정 — 여기가 승부처

상대가 **내 기수 원뿔(ATA<30°) 안 + 사거리(500~3,000ft) 안**에 있으면 매초
피해를 준다:

```
피해 = 50 HP/s × 각도계수     (거리계수는 없다 — 대역 안이면 거리 무관 균일)
500 ft 미만 = 피해 0 (과접근 페널티)
3,000 ft 초과 = 피해 0
```

| ATA | 각도계수 | 피해율 |
|---|---|---|
| < 2° | 1.00 | 50.0 HP/s |
| < 10° | 0.75 | 37.5 HP/s |
| < 20° | 0.50 | 25.0 HP/s |
| < 30° | 0.25 | 12.5 HP/s |
| ≥ 30° | 0 | 0 |

**가장 중요한 문장 하나**: 거리 계수가 없으므로 **"1,800ft에서 정조준"이
"900ft에서 빗나간 조준"보다 아프다.** 신입이 가장 많이 하는 착각이
"가까이 붙으면 이긴다"인데, 이 대회는 **각도(ATA)를 줄이는 쪽**이 이긴다.
격추(100HP)에 필요한 조준 시간: ATA<2°는 2.0초, <30°는 8.0초 — 4배 차이다.

## 2.5 승패 판정 순서 (위가 먼저 적용됨)

| # | 사유 | 결과 |
|---|---|---|
| 1 | 하드덱(고도<1,000ft) | 위반자 즉시 패 |
| 2 | 실속(100kt 미만 10초 누적) | 위반자 즉시 패 |
| 3 | 상대 HP 0 | 격추승 |
| 4 | 제출물 오류/트리 예외 | 해당 측 실격패 |
| 5 | 엔진 지연 안전장치 | 무승부 |
| 6 | **무교전**(300초 만료, 양측 피해 0) | **쌍방 패**(둘 다 0점!) |
| 7 | 300초 만료(피해 교환 있었음) | 잔여 HP 우세 측 승 |

**#6이 신입이 특히 조심해야 할 함정이다.** "일단 도망 다니면 무승부는 되겠지"가
틀렸다 — 한 번도 안 맞고 안 맞혔으면 **양쪽 다 0점**이다. 무승부를 얻고 싶어도
최소한 한 발은 주고받아야 한다. 이격·에너지 회복 자체는 처벌 대상이 아니지만,
300초 내내 한 번도 교전하지 않으면 최악의 결과가 된다.

> 이 프로젝트의 첫 40경기 배터리에서도 **7경기가 이 무접촉 쌍방 패였다** —
> 도망형 상대(`red_extender`)에게 못 따라잡혀서였다. 흔한 함정이라는 뜻이다.
> [06장](06_lessons_from_the_trenches.md)에서 이 원인을 실제로 추적한 과정을
> 볼 수 있다.

## 2.6 순위는 이렇게 매긴다

승점(승3/무1/패0) → 평균 HP 득실차 → 격추승 수 → 제출 시각, 순서로 비교한다.
위 키가 같을 때만 아래 키를 본다.

## 2.7 튜닝 파라미터 — 두 계층

- **액션 파라미터** (`action:` 블록마다 국면별로 다르게 주는 값): `pursuit`,
  `g_burst`, `g_full_ata_deg`, `aim_above_ft`, `lead_time_s`/`lag_dist_ft`,
  `track_rng_ft`/`track_ata_deg`, `cz_range_ft`, `mode`. 각각의 뜻은
  [3장](03_behavior_trees_101.md)에서 설명한다.
- **교리(doctrine) 파라미터** (에이전트 전역에 하나씩): `g_min`,
  `fighting_kts_lo/hi`, `energy_margin_lo/hi` 등. `doctrine:` 블록으로
  범위 안에서 조정 가능하다(개방됨, 2026-08-17).
- **범위 밖 값·미지 키 = 제출 거부**(`disqualified`가 아니라 **검증 단계에서
  거부**된다) — `tools/validate_agent.py`가 서버와 같은 검증을 해준다.
- **`max_g`는 2026-08-24부로 폐지**됐다. 옛 예제나 자료에 이 키가 보이면
  무시할 것 — 지금 쓰면 제출이 거부된다. 대신 `g_burst`/`g_full_ata_deg`/
  `track_rng_ft`/`track_ata_deg` 조합을 쓴다.
